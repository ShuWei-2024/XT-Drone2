# 安全与故障恢复

[返回实物索引](README.md)

至少验证以下故障：

- FAST-LIVO2 odom 过期或停止；
- 局部地图 readiness 失效；
- 规划器心跳或执行桥失联；
- uXRCE-DDS、USB、UART 或网络断开；
- External Vision 丢失或重置；
- PX4 退出 Offboard；
- 低电量、遥控接管和急停。

保护动作必须明确且与场地相符：冻结/悬停、返航或降落。每种动作都要确认旧轨迹不会继续发送、PX4 failsafe 已接管、人工遥控仍可接管，并保存触发时间和恢复结果。

真实飞行不能依赖 Gazebo 真值、静态背景模型或预先生成的仿真降落网格。
