# 实物硬件信息

[返回实物索引](README.md)

在接线和烧录前填写以下清单，具体型号不能用“同系列”代替：

| 类别 | 记录项 |
| --- | --- |
| 飞控 | 型号、MCU、固件 target、串口、电源和固件版本 |
| 伴随计算机 | RK3588 板卡型号、内存、系统、散热、存储和供电 |
| LiDAR | Mid-360 型号、IP、网口、电源、安装位置和驱动版本 |
| 相机 | D435i 序列号、USB 端口、RGB/Depth/IMU 配置和帧率 |
| 机体 | 电机、桨叶、电池、机架、起飞重量和遥控器 |
| 连接 | USB/UART/UDP、端口、波特率、线缆、共地和网络拓扑 |
| 安全 | 急停、人工接管、桨叶拆除工具、测试场地和降落区 |

传感器固定方式和朝向需要拍照并记录坐标系。任何更换线缆、安装位置、相机分辨率或飞控 target 后，都应重新做时间和外参审计。
