# 实物日志与排障

[返回实物索引](README.md)

每次运行至少保存：

- PX4 ULog 和参数导出；
- Agent、ROS 2、FAST-LIVO2、地图、规划器和执行桥日志；
- 传感器话题频率和输入审计；
- TF/外参版本；
- 温度、CPU、内存和网络统计；
- 飞行目标、实际轨迹和故障时间线。

排障顺序：

```text
供电/接线
 -> PX4 状态
 -> Agent/DDS
 -> 传感器话题
 -> 时间戳和 TF
 -> FAST-LIVO2
 -> 地图/readiness
 -> 规划轨迹
 -> Offboard/PX4 控制
 -> 机体动力学
```

一次只改变一个因素，记录变更前后的参数和结果。优先修复根因，不用无限放宽超时或关闭保护来制造“成功”。
