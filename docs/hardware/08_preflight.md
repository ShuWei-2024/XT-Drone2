# 飞行前测试

[返回实物索引](README.md)

按风险递增执行：

| 阶段 | 条件 | 通过标准 |
| --- | --- | --- |
| 通信 | 不解锁、不装桨 | PX4 状态、电池和时间消息持续更新 |
| 传感器 | 机体固定 | 点云、RGB、IMU 频率和时间戳稳定 |
| FAST-LIVO2 | 机体固定/手持慢移 | odom 新鲜、无持续缺口、内存受控 |
| 地图规划 | 不解锁 | readiness、障碍物和轨迹有效性正确 |
| External Vision | 受控输入 | 日志确认选择的 XY/Z/yaw/速度融合状态 |
| Offboard | 拆桨 | setpoint 连续，断链和 readiness 失效能退出 |
| 起飞前 | 有人工接管 | PX4、遥控、电池、急停和降落区全部可用 |

任一阶段失败都先保存日志和参数，再决定是否修复或回退；不能通过放宽保护阈值掩盖问题。
