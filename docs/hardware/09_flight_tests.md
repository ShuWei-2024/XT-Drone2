# 实物飞行实验

[返回实物索引](README.md)

推荐顺序：

```text
人工接管悬停
  -> 自动定点悬停
  -> 0.5 m 前进
  -> 0.5 m 侧移
  -> 返回和降落
  -> 单航点
  -> 多航点
  -> 开阔环境规划
  -> 大安全距离绕障
```

每次实验记录：飞行编号、固件/ROS 版本、参数哈希、传感器配置、目标点、实际轨迹、最大误差、最小障碍距离、odom 年龄、External Vision 状态、ULog、ROS 日志和最终状态。

未通过时先判断是定位、规划、执行桥、PX4 控制还是机体动力学问题；不要直接把同一仿真结论复制到真机。
