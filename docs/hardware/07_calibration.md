# 标定、TF 与时间同步

[返回实物索引](README.md)

必须分别标定和审计：

```text
LiDAR -> IMU
Camera -> IMU
传感器 -> 机体
机体 -> PX4
ENU / FAST-LIVO2 -> PX4 NED
传感器测量时刻 -> ROS / PX4 时间
```

检查顺序：

1. 固定机体，确认 TF 树闭合、方向和杆臂；
2. 记录静止传感器时间戳，检查单调性和消息缺口；
3. 手持做小范围平移/旋转，比较测量时间而不是回调时间；
4. 检查 FAST-LIVO2 与 PX4 的 XY、Z、yaw 和原点；
5. 如启用 External Vision，查看 PX4 日志中的实际融合标志；
6. 保存标定参数、样本数据和审计报告。

“参数已设置”不等于“PX4 已融合”；必须用 PX4 日志和时间配对证据确认。
