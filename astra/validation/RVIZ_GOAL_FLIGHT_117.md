# 三维地图与连续航点飞行（隔离 PX4 1.17 SITL）

界面由 RViz2 和旁边的中文任务控制窗口组成。RViz 显示三维地图、相机画面、
估计位置、已飞路径、EGO 规划轨迹和编号航点；控制窗口管理任务。
入口限定当前准备好的 Replica office4 静态扫描房间，不连接实物。
控制窗口使用系统 `python3-pyqt5`（当前电脑已安装），相机显示使用 RViz 自带 Image。

## 启动

```bash
cd /home/cyf/dev/XT-Drone2-astra
bash astra/rviz_flight_117.bash
```

默认地面选点不限时，未点击开始任务时保持未解锁；Ctrl+C 或关闭控制窗口退出。
可指定新日志目录和选点限时（30–600 秒，0 表示不限时）：

```bash
bash astra/rviz_flight_117.bash my_mission --rviz-goal-timeout-sec 600
```

可同时打开 Gazebo：

```bash
GZ_PARTITION=astra_px4_117 gz sim -g
```

## 看地图

- 默认 Orbit 三维视角：左键拖动旋转，中键拖动平移，滚轮缩放。
  选点时用 **2D Goal Pose**（G），按住左键拖动再松开。
  工具名称中的 2D 只表示点击设置 XY；地图和规划轨迹仍是三维的。
- Views 中保存了 `Top down selection` 和 `3D room view`，可切换方便选点。
- `Onboard RGB camera` 显示机载仿真相机正在看到的真实扫描场景。
- `Reconstructed colour map` 是 FAST-LIVO2 彩色观测累积成的显示地图，
  看过的区域才会出现，雷达和相机视野外不会自动补齐。
- `Scanned room background (display only)` 是导入的完整扫描模型背景，
  有原扫描颜色，半透明显示。可在 Displays 取消勾选，单独看实时建图。
  背景根据起飞前静止的真值/估计位置差做一次显示平移，不能拿它认证定位精度。
  背景和显示地图都不进入规划器或 setpoint。
- 橙色点：局部障碍物（默认隐藏，可勾选 `Stored local obstacles`）；
  蓝线：FAST-LIVO2 估计路径；红线：EGO 控制点折线。
  实际执行的是经过检查的 B-spline；绿色小格：检查过的下降区域。
  黄色球和数字：航点；已到达的航点改成绿色。

## 设置任务

1. 等中文控制窗口显示 **READY**，飞机保持未解锁。
   启动健康检查至少采集 12 秒；暂时不达标时继续等待，最多 60 秒。
   最近 10 秒地图 readiness 至少 95%，且当前必须为 true；不降低原有新鲜度门限。
   超时才退出，终端列出失败项，详细记录保存在本次运行的 `preflight_health.json`。
2. 在 RViz 点选目标，或在控制窗口填写 X/Y 后点击 **添加坐标航点**。
   航点列表显示按 `camera_init` 坐标表示的位置。
3. 起飞前可以连续选点、删除末点、清空列表；点击本身不会起飞。
4. 选择任务结束方式，再点击 **开始任务（起飞）**：
   - **最后一个航点：降落，不返回**：依次执行列表，在最后目标处降落。
   - **最后一个航点：悬停，等待追加目标**：到点后持续保持，追加目标后继续规划。
5. 空中允许追加航点，加入队尾；当前目标不被新点击覆盖。
   起飞/坐标校准和降落期间锁定编辑。
6. **暂停并保持当前位置**：退出轨迹采样，由唯一监督程序保持暂停时的 PX4 位姿。
   **继续并重新规划**：从当前状态重新请求轨迹，不继续执行暂停前的旧时间段。
7. **结束飞行并受控降落** 或关闭控制窗口：中止任务、保持并受控降落。
   RViz 的 **Publish Point** 点击可见点/绿色格仍可触发同样停止流程。

当前场景巡航高度固定为相对起飞点 0.90 m，起飞航向校准先到 1.60 m。
高度展示在控制窗口中，暂不能任意改高，以免离开本房间经过检查的飞行范围。
每次会话最多 8 个航点，连续航点至少相隔 0.15 m；目标离起飞参考不超过 3 m。
第一点至少离起飞点 0.25 m，后续允许主动选择回到起飞点，但不自动添加返航点。

等待下一航点和暂停均有 30–120 秒超时（默认 60 秒），超时后降落。
低电量、失去控制窗口心跳、定位/地图失效、重置或边界保护也会结束飞行。
因此“连续飞行”表示可以继续下发任务，不表示无人操作无限悬停。

## 保护与性能

`/astra/ui/goal`、`/astra/ui/command` 是操作请求，由同一个飞行监督程序检查。
控制窗口不直接发布规划器目标或 `/fmu/in/*`。
命令检查当前会话、2 秒时间戳和请求序号，旧窗口/重复消息不能重启任务。
控制窗口心跳 2 Hz，失联 2 秒触发受控降落；电池消息最大允许 3 秒陈旧，
剩余电量低于 20% 或 PX4 低电量告警时停止任务。

定位/readiness/飞控/规划器仍使用已有 250 ms 新鲜度保护。
目标需要完整覆盖 0.10 m 下降区域储备，不能落入膨胀的实时障碍物；
编辑时、点击开始时和目标实际派发时都检查。保留单一 setpoint 发布者、
固定 ENU/NED 变换、测量时间高度检查、实际边界和 0.55 m 已知表面距离门限。
目标可接受不等于保证路线完成：规划失败或保护触发仍会降落。

彩色显示地图运行在独立进程，以 1 Hz 输出、0.10 m 体素、最多 60000 点、
180 秒保留时间控制显示规模。相机和显示队列浅缓存，避免把重建显示工作放到控制循环。
扫描缺口、动态障碍、任意室内区域和旋翼外缘距离仍未认证。
30 秒到点等待实测真值横向最大偏移 0.107 m、Z 跨度 0.123 m，
等待功能已通过，但没有认证高精度贴障悬停，继续保留已有安全余量。
